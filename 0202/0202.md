# Solución Ejercicio 2 - Simulación de iteración ágil

## Iteración 1 — Funcionalidades básicas

### Tarjeta CRC: 'Artículo'

| Clase: Artículo | |
|---|---|
| **Responsabilidades** | **Colaboradores** |
| Conocer su nombre y precio unitario | - |

### Tarjeta CRC: 'Carrito'

| Clase: Carrito | |
|---|---|
| **Responsabilidades** | **Colaboradores** |
| Añadir artículos | 'Artículo' |
| Calcular el total | 'Artículo' |
| Conocer cuántos artículos contiene | 'Artículo' |

### Casos de prueba

- Un carrito vacío tiene total 0.

    Un carrito sin artículos cuenta con un total de 0, no hay ninguno añadido y por lo tanto el carrito está vacío.

- Tras añadir dos artículos, el total es la suma correcta de sus precios.

    Si se añaden dos artículos, se suma el precio de ambos y el carrito muestra el importe total, indicando además que hay dos artículos.

## Iteración 2 - Funcionalidades tras revisión con el cliente

| Conocer su nombre y precio unitario | - |

### Tarjeta CRC: 'Carrito'

| Clase: Carrito | |
|---|---|
| **Responsabilidades** | **Colaboradores** |
| Añadir artículos | 'Artículo' |
| Eliminar artículos por nombre | 'Artículo' |
| Calcular el total | 'Artículo' |
| Calcular el total con descuento porcentual aplicado| 'Artículo' |
| Conocer cuántos artículos contiene | 'Artículo' |

### Casos de prueba

- Si se quiere eliminar algún artículo del carrito por nombre, como por ejemplo "Consola", este desaparece del carrito.
- Si el nombre del artículo que se quiere eliminar en el carrito no existe, la cantidad de artículos en el carrito no cambia, no se elimina nada.
- Cuando el carrito calcule el precio total de la suma de los artículos (o de un único artículo), si se considera oportuno, este aplica un descuento porcentual sobre el importe total y muestra el precio final con el descuento aplicado.
- Si no se realiza ningún descuento, el carrito no lo aplicará y simplemente mostrará el importe total sin este.
